Build notes — The Houseplant Out-of-Office

The entry is a single out-of-office auto-reply written as if a houseplant
sent it. The program is one small TypeScript file at the repository root.
Running it writes the reply to the output entry file the grader reads.

The first draft read as a plain office reply with a plant detail at the end:
out of office until watered, last drink in March, and the fern holding the
passwords. It was funny in outline but soft, because the conditional phrasing
buried the punchline.

The revision tightened it in two ways. First, the conditional became a blunt
question, so the reply snaps instead of hedging. Second, it added a darker
second half to the password joke: the fern holds not only the passwords but
also what is left of the plant's will to live. That line is the joke the
judge is asked to weigh: the plant's own neglected life, no water since
March, drives it, and it lands as a surprise rather than a stock office
phrase. The final text is 114 characters, inside the 120 limit.

The repository also carries the make.fun badges in the readme, linked to the
bounty page, and an MIT license file.
